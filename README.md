# MEDFINITY-Surgical-Equipment
Medfinity Website — Version 2
================================
Premium responsive healthcare-equipment catalogue.

Includes:
- Individual product cards with high-resolution brochure crops
- Product names and brochure page references
- "Price on request" where the supplied brochure does not provide prices
- Search and category filtering
- Enquiry form (email)
- WhatsApp quotation button
- Full brochure viewer
- Responsive mobile/desktop design
- Original brochure included

Open index.html in Chrome/Edge after extracting the ZIP.
